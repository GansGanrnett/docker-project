# Правила работы с репозиторием

## MongoDB Driver

Для миграций использовать только простейшие типизированные операции:
`Find(...).ToListAsync()` по полным моделям и `UpdateOneModel<T>` /
`BulkWriteAsync`.

Не использовать:

- raw-BSON в запросах и обновлениях,
- проекции на computed fields,
- `$`-ссылки в классическом `$set` (сервер разворачивает поле-ссылки
  только в aggregation pipeline, а не в обычном `$set`),
- `BsonDocument` в проекциях.

Если нужна продвинутая функция — сначала проверить API локальным probe,
потом коммитить.

Основание: PR #42 (issue #34). Миграция статусов заказа потребовала пяти
раундов правок именно из-за этих четырёх приёмов — `$ifNull` сохранился
как литерал, `BsonDocumentArray` в драйвере 2.23 отсутствует, `$CreatedAt`
записался строкой, проекция на класс без BSON-атрибутов молча вернула
дефолты, `BsonDocument` в проекции не перевёлся вовсе. Рабочий вариант —
чтение полных типизированных моделей плюс `BulkWrite`. Лишние поля в
памяти на разовом скрипте дешевле кода, поведение которого нельзя
предсказать.
